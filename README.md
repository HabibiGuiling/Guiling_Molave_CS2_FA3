# Guiling_Molave_CS2_FA3

## Description
- My 1st solution prompts the user to input a password then, it validates whether or not the password is between 8 characters and 15 characters. It displays whether if its valid or not. Lastly, if it is not valid then it prompts the user to input a different password.

- My 2nd solution asks the user to input his/her credit score, annual income, and years in current job. Then with the given criteria such as whether the credit score is 700 or higher, etc. will display whether if the Loan is approved or Denied

## How to Run
1. Open the programs.
2. Run the programs.
3. Enter the required value(s).

## Input Needed
- The value that you need to input for the first program is password.
- The values you need to input for the second program are credit_score, annual_income, and years_in_current_job.
